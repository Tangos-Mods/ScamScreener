## ScamScreener 2.7.0

This release adds Minecraft `26.3.x` support.

- added Minecraft `26.3.x` builds next to `26.2.x` and `26.1.x`
- updated the client to the `26.3` input and link handling, so screens, keyboard and mouse navigation, the Training Hub link, and `/ss profiler open` keep working on the new version
- Fabric Loader `0.19.3` or newer is now required
- updated build dependencies (Fabric API, Mod Menu, Gradle, Stonecutter, Fabric Loom)
